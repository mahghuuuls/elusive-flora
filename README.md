# Elusive Flora

A Minecraft 1.12.2 Forge mod. Adds rare plants that grow only in specific biomes and situations:
ocean floors, cliff faces, full-moon nights, winter, and more, across the Overworld, Nether, End,
and Aether. A journal hints where each one grows. Plants regrow where they were found and cannot
be moved or farmed.

Requires Patchouli 1.0-28 or newer on client and server. Serene Seasons is optional.

Repository documentation is written at release. This file is a placeholder for the initialized
project baseline.
